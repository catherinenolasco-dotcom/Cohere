# Catherine Nolasco | Portfolio

A single-file virtual portfolio for the Manager, People Operations, Data & Reporting role at Cohere. Styled after a company careers site. This is an independent portfolio and is not affiliated with Cohere.

## What is inside

- `index.html`: the whole site. Fonts, headshot, logos and illustrations are embedded, so there are no other files to host.
- `.nojekyll`: tells GitHub Pages to serve the file as is.

## Run it locally

Open `index.html` in any browser. No build step.

## Deploy with GitHub Pages

1. Create a new repository and push these files to the `main` branch.
2. In the repository, go to Settings, then Pages.
3. Under Build and deployment, choose "Deploy from a branch", select `main` and `/ (root)`, and save.
4. The site goes live at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

Netlify, Vercel and Cloudflare Pages also work: drag the folder in, no build command needed.
